핵심 업무 흐름 검증

  1. 대표가 업무를 지시한다.
  2. 본부장이 업무를 분석하고 담당 팀과 직원을 배정한다.
  3. 전문 직원이 실제 업무를 수행하고 필요한 경우 협업한다.
  4. 팀장이 결과물을 검수하고 오류가 있으면 수정한다.
  5. 본부장이 최종 결과를 정리하여 대표에게 보고한다.
  6. 대표가 최종 승인한다.

위 단계 전체가 실제로 작동하는지 확인하는 것을 1차 개발 목표로 합니다.

현재 주요 확인 과제

  • Gemini 무료 API의 Cloudflare 호출 오류 해결
  • 본부장 업무 분석 및 직원 배정 검증
  • 전문 직원의 실제 업무 수행 및 팀 간 협업 검증
  • 검수·수정·대표 보고·승인 흐름 검증
  • 데이터 백업 및 복구 가능 여부 검증
  • AI 및 서버 오류 로그 관리 확인

GitHub 최근 업데이트

저장소의 최근 커밋을 조회합니다. 커밋은 코드 변경 이력이며, 실제 기능 완료 여부를 의미하지 않습니다.

커밋 정보를 불러오는 중입니다.

개발률 산정 원칙

  • 코드 작성만으로 완료 처리하지 않습니다.
  • 개별 기능의 실제 작동 테스트가 필요합니다.
  • 다른 기능과의 연결 및 통합 테스트를 확인합니다.
  • 오류 수정 및 재검증까지 완료해야 합니다.
  • 최종 검수 결과를 반영하여 개발률을 산정합니다.

- PR #11에서 3D 사무실 화면을 최신 main에 재적용하고 병합했다.
- `index.html`은 기본 진입점으로 `office3d.html`을 연다.
- `office-map.html`은 직원 목록 중심의 보조 화면이며 3D 화면과 상호 이동할 수 있다.
- 대표이사는 단테, 법무팀장은 피터로 수정하고 브라우저 테스트에서 확인했다.
- 3D 화면·업무 이력·대표 결정 UI에 대한 Playwright 테스트와 Cloudflare Pages 프리뷰가 통과했다.
- 기존 Worker, Secret, D1 스키마/데이터는 변경하지 않았다.

## 완료 — 우선순위 1 대표 지시 및 본부장 라우팅 (2026-11-23)
- PR #12 병합 완료: 대표 단테(CEO)를 선택해 업무를 지시하면 본부장 알렉스(COO)에게 전달한다.
- 본부장 이름은 화면·요청 payload 모두 알렉스로 전달한다.
- 전문 직원을 직접 선택한 경우 기존 직원별 업무 지시 경로를 유지한다.
- 3D 브라우저 회귀 테스트에서 단테→알렉스 라우팅과 피터 직접 지시 경로를 검증했다. 테스트 실행 #45128921173 통과.
- Worker, Secret, D1 스키마/데이터는 변경하지 않았다.

## 우선순위 2 — 전문 직원 수행 및 협업

## 우선순위 2 — 전문 직원 수행 및 협업
- 직원 명단, 팀장, 전문 직무 매핑이 조직도와 일치하는지 검증한다.
- 1~3명의 전문 직원이 실제로 배정되고, 팀장이 결과를 검수하는지 확인한다.
- 화면의 직원 상태는 서버 업무 이력과 실제 담당자 결과를 근거로 표시한다. 추정 상태를 완료로 표시하지 않는다.

## 우선순위 3 — 재시도·중단·재개
- taskId/idempotencyKey로 중복 접수를 막는다.
- 네트워크 오류, 시간초과, AI 한도 초과 때 기존 업무를 보존하고 동일 업무 ID로 재개한다.
- 사용자에게 실제 진행 단계, 오류 원인, 재개 여부를 표시한다.

## 우선순위 4 — 검수·보고·대표 승인
- 전문 직원 결과와 팀장 검수 결과가 본부장 최종 보고에 반영되는지 확인한다.
- 대표 승인/반려는 대표 전용 인증을 사용하고 서버 이력에 남긴다.
- 검수 통과 전 대표 승인 버튼이 잠기는지, 새로고침 후 결과물과 감사 이력이 복원되는지 검증한다.

## 우선순위 5 — 3D 사무실 및 사용성
- 3D 캐릭터 상태·대화·업무 이력 표시가 실제 업무 데이터와 일치하는지 개선한다.
- 데스크톱 및 iPad에서 업무 지시·대화·이력 기능을 검증한다.
- 사용자가 확정한 TEAM.AI.ID 레퍼런스의 공간 구성과 기존 가구 배치를 근거 없이 변경하지 않는다.

## 변경 금지 및 외부 확인 필요
- 운영 Worker 배포, Secret 변경, 운영 D1 스키마/데이터 변경, 백업 복원, Cloudflare 배포 설정 변경은 자동 에이전트가 수행하지 않는다.
- 운영 Worker/D1의 실제 상태와 실사용 end-to-end 검증은 운영 계정 접근 및 안전한 테스트 절차가 확인된 후 수행한다.
- 승인 원본 HTML, `index.html`, 배포 워크플로는 자동 에이전트가 변경하지 않는다.

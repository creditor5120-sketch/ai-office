# SW AI OFFICE 3D 업무 엔진 연결 작업 기록

## 목적
기존 3D 사무실 화면을 유지하면서 대표가 본부장 알렉스에게 전달한 지시를 실제 SW AI OFFICE Worker로 연결한다. 3D 화면의 기존 직원 간 개인 대화는 유지하고, 알렉스에게 전달한 메시지만 업무처리 엔진으로 보낸다.

## 이번 변경
- `index.html`의 알렉스 메시지 전송 분기를 실제 업무처리 호출로 변경했다.
- 직원 명단은 3D 사무실의 `state.staff`에서 읽는다.
- 대표이사 피터를 Worker가 요구하는 `COO` 직원 ID로 변환한다.
- 직원별 이름·팀·직책·담당 지침을 Worker 입력 명단에 포함한다.
- 업무 ID와 멱등성 키를 생성하고, 중단된 업무는 동일 지시·직원 명단일 때 24시간 이내 재사용한다.
- 처리 중에는 알렉스 대화창에 Worker 진행 단계를 표시한다.
- 완료·부분 완료·미완료를 구분해 표시하고, 결과물 및 검수·대표 승인 상태를 함께 출력한다.
- 연결 또는 실행 실패 시 가짜 확인 응답을 반환하지 않고 실패 사유를 표시한다.
- `office3d-integrated.html`을 새 실행 진입점으로 추가했다. 이 파일은 3D `index.html`을 iframe으로 열고, 기존 Worker 인증·업무 이력·대표 승인 패널을 제공한다.
- 일반 서버 인증값과 대표 승인 인증값은 실행 화면의 세션 저장소에만 보관한다. 비밀값은 코드나 저장소에 포함하지 않는다.

## 확인한 사항
- 3D 사무실 HTML의 JavaScript 구문 검사: 통과
- 3D 통합 실행 래퍼 JavaScript 구문 검사: 통과
- GitHub Actions 실행 `44857547351` (커밋 `5bbda2808552044d9ebe1e5e19531cc7ad3fedca`): 성공
  - 3D 브라우저 스모크 테스트
  - Worker 인증·대표 승인·감사 계약 테스트
  - v3.15 업무연동 브리지 테스트
  - 시각 증거 업로드

## 아직 검증되지 않은 사항
- 새 `office3d-integrated.html`을 실제 Cloudflare Pages 미리보기에서 열어 인증값을 입력하는 브라우저 통합 테스트
- 현재 운영 Worker가 이 브랜치의 최신 Worker 코드와 일치하는지 확인
- 운영 D1 실제 스키마와 백업·복구 상태 확인
- 대표 지시부터 직원 수행·검수·최종 보고까지 실제 API를 이용한 E2E 업무 1건
- 첨부 파일의 실제 본문 전달. 현재 메시지 첨부는 파일명만 UI에 표시하며 Worker 요청 본문에 파일 바이트를 전달하지 않는다.

## 안전 경계
- 운영 Worker 배포, D1 변경, Secret 변경, GitHub Pages 공개 배포, PR 병합은 수행하지 않는다.
- 기존 승인 원본과 기존 3D 사무실 원본 파일은 덮어쓰지 않는다.
- 실제 E2E 검증 전에는 운영 가능 또는 업무 완료로 판정하지 않는다.

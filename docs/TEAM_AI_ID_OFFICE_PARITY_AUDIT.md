## 1. 실제 참조 화면에서 확인한 사항

2026-11-20 공개 쇼케이스 화면을 브라우저로 캡처해 확인했다. 확보된 기준 캡처는 2층 화면이다.

- 직사각형에 가까운 넓은 단일 층 평면을 여러 실과 업무 구역으로 나눈 구조.
- 외곽은 비교적 높은 벽, 내부는 불투명 파티션과 유리 파티션을 혼합.
- 중앙부에 복도와 유리 출입 구획이 있고, 양쪽과 후면에 여러 팀의 책상 군집이 배치됨.
- 책상마다 모니터·의자·소품이 있고, 직원 캐릭터는 입체형 사람 모델과 이름표로 표현됨.
- 전면 하단에는 라운지/휴게 구역, 소파, 원형 좌석 및 계단처럼 보이는 구조물이 있음.
- 바닥은 구역별로 회색·청회색·베이지·연한 분홍 계열의 타일 패턴으로 구분됨.
- 화면 하단에 1층/2층 및 2D/3D 전환 컨트롤이 배치됨.

참조 화면의 모든 세부 치수·텍스처·모델 원본은 공개 텍스트로 확인되지 않는다. 캡처로 확인한 외형을 기준으로 독립적으로 재구성하며, 확인되지 않은 수치나 자산을 원본과 동일하다고 단정하지 않는다.

## 2. 현재 SW AI OFFICE 구현 확인

- Three.js 기반 3D 장면.
- 1층: 대표실, 카페테리아, IT·기술팀, 로비, 회의실, 본부장실 및 5개 팀의 업무 공간.
- 2층: 1층의 단순 복제 구조를 제거하고 별도 장면으로 재구성.
- 2층: 5개 팀 구역, 30개 작업석, 회의·협업실, 라운지·휴게공간을 별도로 배치.
- 33명 직원 캐릭터를 2층 작업석과 협업 공간에 별도로 배치.
- 1층/2층 전환 시 각 층의 공간과 캐릭터 그룹을 전환.
- 2D/3D 시점 전환 및 직원 선택·대화 기능 유지.
- 2026-11-20 GitHub Actions 브라우저 테스트에서 2층 독립 구조, 5개 팀, 30개 작업석, 33개 캐릭터 및 층 전환 검증 통과.

## 4. 다음 구현 순서

1. TEAM.AI.ID 1층 화면도 별도 캡처해 1층/2층 기준 자료를 완성한다.
2. 2층 바닥을 구역별 타일 패턴으로 나누고, 기준 화면의 바닥 색상·격자 방향을 반영한다.
3. 외곽 벽, 중앙 복도, 불투명 파티션, 유리 출입 구획을 재배치한다.
4. 책상 군집·모니터·의자·수납장·라운지 가구를 기준 화면의 밀도와 형태에 맞춰 보강한다.
5. 픽셀 스프라이트를 입체형 캐릭터 표현으로 교체하고 이름표·업무 상태·상호작용을 유지한다.
6. 카메라 시점과 전체 공간 비율을 참조 캡처와 비교해 조정한다.

## 5. 승인 및 검증 원칙

- 기존 업무 처리 기능과 Worker 연동을 시각 작업 때문에 제거하지 않는다.
- main 브랜치 병합 및 운영 Worker/D1 변경은 별도 승인 없이는 하지 않는다.
- 실제 화면을 비교하지 못한 항목은 완료 처리하지 않는다.
- "100% 동일" 판정은 층별 전체 화면, 바닥, 공간 배치, 가구, 캐릭터, 애니메이션, 카메라/조작을 직접 비교한 후에만 내린다.
- TEAM.AI.ID의 원본 모델·텍스처·코드 등 권리 확인이 필요한 자산은 무단 복제하지 않는다. 필요한 경우 사용 허가를 받거나 외형을 독립 제작해 화면상 동등성을 목표로 한다.

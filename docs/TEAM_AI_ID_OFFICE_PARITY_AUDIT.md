# TEAM.AI.ID 사무실 시각적 동등성 점검표

작성일: 2026-11-20
대상 브랜치: work/office3d-integration
대상 구현: office3d.html
참조 페이지: https://team.ai.id/office/
공개 데모: https://team.ai.id/showcase/?showcase=1

## 1. 확인 가능한 참조 정보

TEAM.AI.ID 공식 홈페이지의 공개 설명에서 확인한 사항:
- 3D 가상 사무실 데모를 제공한다.
- 데모 소개 문구는 1층·2층과 26명의 실시간 에이전트를 명시한다.
- 마우스로 드래그해 시점을 회전할 수 있다고 안내한다.
- 1층/2층 전환과 2D/3D 전환을 안내한다.
- 에이전트는 각자 책상에 배치되며, 클릭해 대화하고 작업 상태를 확인하는 제품 경험을 설명한다.

주의: 공개 데모 경로는 검색/텍스트 브라우저에서 동적으로 렌더링된 내부 3D 장면이나 모델 파일을 노출하지 않았다. 따라서 실제 바닥 타일 패턴, 가구 치수·모델, 캐릭터 외형·애니메이션, 조명·카메라 초기값은 아직 확인되지 않았다. 확인하지 못한 세부사항을 추정해 동일하다고 판정하지 않는다.

## 2. 현재 SW AI OFFICE 구현 확인

현재 office3d.html에서 확인한 사항:
- Three.js 기반 단일 층 장면.
- 56 x 38 크기의 연속 바닥과 여러 공간을 기본 도형으로 구성.
- 사업본부, 회의실, 본부장실, 대표실, 카페테리아, IT·기술팀, 로비 배치.
- 직원은 CanvasTexture 기반 픽셀 스프라이트로 생성.
- 책상·의자·테이블·소파 등은 기본 Three.js 도형 조합.
- 직원 수는 직원 데이터와 대표 캐릭터를 포함해 33명으로 테스트에서 확인됨.
- 2D/3D 시점 전환과 마우스 회전·확대가 구현되어 있음.
- 1층/2층 선택 UI와 실제 층별 모델은 확인되지 않음.

## 4. 다음 구현 순서

1. 공개 데모의 실제 렌더링 화면과 상호작용을 관찰할 수 있는 기준자료 확보.
2. 장면을 층별로 분리하고 1층/2층 전환 구조 설계.
3. 바닥 패턴·벽·공간 경계·조명·카메라를 기준 화면에 맞춰 재구성.
4. 가구 모델을 기준 화면의 형태·크기·배치에 맞춰 교체.
5. 캐릭터 외형, 이름표, 걷기/착석/업무 동작을 기준 화면에 맞춰 교체.
6. 기존 직원 클릭, 대화, 실제 업무 상태 연동을 유지한 채 브라우저 스모크 테스트.

## 5. 승인 및 검증 원칙

- 기존 업무 처리 기능과 Worker 연동을 시각 작업 때문에 제거하지 않는다.
- main 브랜치 병합 및 운영 Worker/D1 변경은 별도 승인 없이는 하지 않는다.
- 실제 화면을 비교하지 못한 항목은 완료 처리하지 않는다.
- "100% 동일" 판정은 층별 전체 화면, 바닥, 공간 배치, 가구, 캐릭터, 애니메이션, 카메라/조작을 직접 비교한 후에만 내린다.
- TEAM.AI.ID의 원본 모델·텍스처·코드 등 권리 확인이 필요한 자산은 무단 복제하지 않는다. 필요한 경우 사용 허가를 받거나 외형을 독립 제작해 화면상 동등성을 목표로 한다.
